Extension 17de83e: boards in tabs

Built with the jsxgraph-quarto extension at aacchhee/jsxgraph-quarto 17de83e (an earlier state of PR #2). The JSXGraph library is the same for every extension version: 1.14.0 from jsDelivr. The figure code comes from old ctm-demo commits, as noted at each board. Each extension version has its own copy of this page: a26aea8 (before PR #1) · 59d549c (upstream main, PR #1) · 17de83e (an earlier state of PR #2) · overview and measurements.

To test a board in a tab: load the page in a wide window, open the tabs named at the board, then make the window narrow (about 390 px) and wide again. A blank board after opening a tab (library problem 1) appears only if Chrome is not painting the window at that moment, for example while it is covered by another window.
