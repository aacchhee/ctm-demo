Gaussian elimination

Your answers are saved only in this browser.

Solve these three systems by forward elimination, followed by back substitution. The last system needs a row swap before elimination can begin.

For an augmented matrix \([A\mid b]\), the last column contains the right-hand side. Apply every row operation to that column too. A pivot is the nonzero entry used to eliminate entries below it. If the proposed pivot is zero, look for a nonzero entry below it and swap rows.

Work on paper first, then check your entries. Use exact numbers such as 1/2. The matrix fields below include the right-hand side as their last column. Follow the specified row operations without further row scaling: other valid elimination routes can produce different intermediate matrices.

3. A 3×3 system that needs pivoting

\[ \begin{aligned} 2y+z&=1,\\ 2x+y-z&=0,\\ x-y+2z&=9. \end{aligned} \qquad [A\mid b]=\begin{bmatrix}0&2&1&1\\2&1&-1&0\\1&-1&2&9\end{bmatrix}. \]

The first proposed pivot is zero, so division by it is impossible. This does not mean the system has no unique solution. Use partial pivoting: in the current column, choose the available entry with the largest absolute value and move its row into the pivot position. Here, compare the entries \(0\), \(2\), and \(1\) in the first column.
