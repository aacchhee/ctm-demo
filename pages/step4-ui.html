The lecture/reading switch

A page with .reading-step blocks gets the switch automatically, at the top of the page. An empty ::: {.modes} block puts it somewhere else, here. The text outside reading steps is the lecture; the reading steps add the details for reading on one’s own. The choice holds for the browser tab, on every page of this site, and a new tab starts in lecture mode.

::: {.modes}
:::

::: {.reading-step title="Go deeper: what the switch does"}
**Explore** (lecture mode) closes this block, **Go deeper** (reading mode)
opens it. The switch opens or closes every `.reading-step` on the page, and
leaves hints, solutions and `.details` blocks as they are.
:::

Saved answers

Write code and a mathematics answer, then reload or leave and reopen this page. The candidate restores both answers in this browser without running Python or checking the mathematics again. Reset brings back the Python starter and deletes that exercise’s saved answer; the mathematics answer stays independent. The page bar can clear saved answers or stop saving. The candidate profile enables the page progress panel for these exercises outside the quiz below.

```{py-exercise}
#| label: step4-ui-autosave
#| caption: Saved in this browser
#| task: Complete double(x) so that it returns twice x.
def double(x):
    pass

## TESTS ##
assert double(2) == 4, "double(2) should be 4."
assert double(-3) == -6, "double(-3) should be -6."
```

```{math-exercise}
#| label: step4-ui-autosave-math
#| caption: Saved in this browser
#| mode: equivalent

$2+2=$ __[4]
```

Also new, without a section of its own

  • Print: printing opens every reading step; the switch is not printed.
  • Keyboard: Tab reaches the switch’s buttons and every summary; Enter and Space open and close a reveal.
  • markdown-lint: true (in _quarto.yml): the render warns about raw HTML (<details>, <iframe>, empty <div id>) and names the Markdown to use instead.
  • Settings: ctm-assessment: modes: false hides the switch (the de page uses it), tab-links: false turns the links into tabs off.
  • This candidate: saved Python and mathematics answers, page progress and the mixed quiz above. Variant approval and exercise text per language remain separate work.
