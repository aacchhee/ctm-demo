**Oppgave 1 — parallellplatekondensator**

::: {#phys-2024-2-1 .math-exercise-context}

En parallellplatekondensator har $d=0.10\,\mathrm{mm}$,
$A=4.0\cdot10^{-4}\,\mathrm{m^2}$ og dielektrisitetskonstant $\kappa=2.0$.
Den lagrede energien er $U_E=1.0\,\mu\mathrm J$. Bestem ladningen og
feltstyrken mellom platene.

:::

```{math-exercise}
#| label: phys-2024-2-1
#| caption: Kondensator
#| mode: numeric
#| tolerance: 3%
#| partial-credit: true
#| context: phys-constants, phys-2024-2-1

$Q=$ __[12] nC

$|\mathbf E|=$ __[1.7] MV/m
```

<details class="solution-block">
<summary>Løsningsforslag</summary>

1.  $\displaystyle U_E=\dfrac{Q^2}{2C} \Rightarrow Q=\sqrt{2U_E\, C} =  \sqrt{ \dfrac{2U_E\,\kappa \epsilon_0 A}{d}}=\underline{\underline{12\,\mathrm{nC}}}$\

2.  $E=\dfrac{Q}{A\kappa \epsilon_0} = \underline{\underline{1.7\,\mathrm{MV/m}}}$\
    Alternativt:

    $\displaystyle U_E=u_E A d = \dfrac{1}{2} \kappa \epsilon_0 E^2 Ad \Rightarrow E=\sqrt{ \dfrac{2U_E}{\kappa \epsilon_0 A d } } = \underline{\underline{1.7\,\mathrm{MV/m}}}$\

</details>

**Oppgave 2 — tre punktladninger**

::: {#phys-2024-2-2 .math-exercise-context}

Tre positive punktladninger ligger på $x$-aksen:
$q_1=25\,\mu\mathrm C$ ved $x=0$, $q_2=10\,\mu\mathrm C$ ved $x=2\,\mathrm m$
og $q_3=20\,\mu\mathrm C$ ved $x=3\,\mathrm m$. Bestem kraften på $q_3$,
feltet ved $x=4\,\mathrm m$, og fluksen ut av en kule med sentrum ved
$x=5\,\mathrm m$ og radius $4\,\mathrm m$. Positive fortegn betyr
$+\hat{\mathbf x}$ eller utadrettet fluks.

:::

```{math-exercise}
#| label: phys-2024-2-2
#| caption: Coulombs lov og Gauss' lov
#| mode: numeric
#| tolerance: 3%
#| partial-credit: true
#| context: phys-constants, phys-2024-2-2

$F_{3x}=$ __[2.3] N

$E_x(4\,\mathrm m)=$ __[0.22] MV/m

$\displaystyle\oint_S\mathbf E\cdot\mathbf n\,dA=$ __[3.4] MV m
```

<details class="solution-block">
<summary>Løsningsforslag</summary>

1.  $\mathbf{F} = \dfrac{kq_1q_3}{\left(r_{31}\right)^2}\, \hat{x} + \dfrac{kq_2q_3}{\left(r_{32}\right)^2}\, \hat{x} = \underline{\underline{(2.3\,\mathrm{N})\,\hat{x}}}$\

2.  $\mathbf{E}(\mathbf{r}_4) = \left( \dfrac{kq_1}{\left(r_{41}\right)^2}\, \hat{x} + \dfrac{kq_2}{\left(r_{42}\right)^2}\, \hat{x} + \dfrac{kq_3}{\left(r_{43}\right)^2}\, \hat{x} \right) = \underline{\underline{(0.22\,\mathrm{MV/m})\,\hat{x}}}$\

3.  $\displaystyle \oint_S \mathbf{E}\cdot \mathbf{n}\,dA = \dfrac{Q_{\mathrm{in}}}{\epsilon_0} = \dfrac{q_2+q_3}{\epsilon_0} = \underline{\underline{3.4\,\mathrm{MVm}}}$\

</details>

**Oppgave 3 — uniformt ladet kule**

::: {#phys-2024-2-3 .math-exercise-context}

En ikke-ledende kule med radius $R=0.10\,\mathrm m$ har total ladning
$Q=20\,\mathrm{mC}$, symmetrisk fordelt i volumet. Bestem feltstyrken i
$\mathbf r_1=(2,2,2)\,\mathrm m$. En partikkel med
$m=6.0\cdot10^{-6}\,\mathrm{kg}$ og $q=2.0\,\mu\mathrm C$ slippes fra ro ved
$0.30\hat{\mathbf x}\,\mathrm m$; bestem hastighetsvektoren langt borte.
Bevegelsen går i $+\hat{\mathbf x}$-retning. Inne i kula er
$\mathbf E=b\mathbf r$; finn $b$ og ladningstettheten $\rho$. Skisser også
de radielle, utadrettede feltlinjene utenfor kula.

:::

```{math-exercise}
#| label: phys-2024-2-3
#| caption: Felt, energi og ladningstetthet
#| mode: numeric
#| tolerance: 4%
#| partial-credit: true
#| context: phys-constants, phys-2024-2-3

$|\mathbf E(2,2,2)|=$ __[15] MV/m

$v_\infty=$ __[20] km/s

$b=$ __[1.8e11] V/m²

$\rho=$ __[4.8] C/m³
```

<details class="solution-block">
<summary>Løsningsforslag</summary>

1.  

2.  $|\mathbf{E}(\mathbf{r}_1)|=\dfrac{kQ}{(r_1)^2} = \underline{\underline{15\,\mathrm{MV/m}}}$\

3.  $V(r)=\dfrac{kQ}{r}$

    Vi ser på situasjonen når $r=r_0$ og når $r=\infty$.

    $\Delta E_p = q\Delta V = q(V(\infty)-V(r_0))  = - \dfrac{kqQ}{r_0}$

    $\Delta E_k = \dfrac{mv^2}{2}-0 =\dfrac{mv^2}{2}$

    $\displaystyle \Delta E_p +\Delta E_k =0 \Rightarrow  - \dfrac{kqQ}{r_0} + \dfrac{mv^2}{2} = 0 \Rightarrow \mathbf{v}= \sqrt{\dfrac{2kqQ}{mr_0}}\,\hat{x} = \underline{\underline{(20\,\mathrm{km/s})\,\hat{x}}}$\

4.  Når $r=R$ må de to uttrykkene være like:

    $\Rightarrow |\mathbf{E}(R\hat{x})|= bR=\dfrac{kQ}{R^2} \Rightarrow b=\dfrac{kQ}{R^3} = \underline{\underline{1.8\cdot 10^{11}\, \mathrm{Vm}^{-2}}}$\
    $\rho(\mathbf{r})=\epsilon_0 \nabla \cdot \mathbf{E} = 3 \epsilon_0 b = \underline{\underline{4.8\,\mathrm{Cm}^{-3}}}$\
    Alternativt:\
    $\rho(\mathbf{r})=\epsilon_0 \nabla \cdot \mathbf{E} = 3 \epsilon_0 b \Rightarrow \rho=\mathrm{konstant} \Rightarrow \rho = \dfrac{Q}{\frac{4}{3} \pi R^3 } = \underline{\underline{4.8\,\mathrm{Cm}^{-3}}}$

    $\Rightarrow b= \dfrac{\rho}{3 \epsilon_0} = \underline{\underline{1.8\cdot 10^{11}\, \mathrm{Vm}^{-2}}}$

</details>
